# dotfiles

Managed with [chezmoi](https://chezmoi.io).

1. Install [Homebrew](https://brew.sh).
2. `brew install chezmoi git && brew install --cask 1password-cli`
3. Sign into 1Password and enable the CLI integration.
4. `chezmoi init --apply keyute`
5. Sign in to Claude Code (`claude`) and to pi with the OpenAI subscription
   (`pi auth`).
